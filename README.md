# Pixel Paintings

Procedurally generated pixel art paintings. Every generation is unique — 25 styles, 32 colour palettes, and an invert mode.

**[Open the app →](https://bert4422.github.io/Pixel-Paintings/)**

---

## Install as an app

### iPhone / iPad
1. Open the link above in **Safari**
2. Tap the **Share** button (box with arrow at the bottom)
3. Tap **"Add to Home Screen"**
4. Tap **Add**

### Android
1. Open the link above in **Chrome**
2. Tap the **three-dot menu** (top right)
3. Tap **"Add to Home Screen"** or **"Install app"**
4. Tap **Add**

### Desktop (Chrome / Edge)
1. Open the link above
2. Click the **install icon** in the address bar (right side)
3. Click **Install**

Once installed it opens fullscreen with no browser UI, just like a native app.

---

## Features

- 25 unique styles — landscapes, fractals, patterns, abstracts
- 32 colour palettes
- Invert mode
- Saves as 1024×1024 PNG
- Works offline after first visit
